# Visual Identity

- **Deep Muse Blue `#0A2463`** is the primary brand colour. Off-palette visual references
  fail brand lint.
- Infinity-loop ribbon; negative-space eye motif. Restrained, engineering-oriented, legible.
- Prefer real artifacts: terminals, commit graphs, CI badges, device screenshots.
- No stock-photo gloss, no neon “AI” gradients, no decorative robots.
- Vertical 9:16 for TikTok/Reels; 16:9 for YouTube; evidence-styled carousel slides for
  Instagram use Deep Muse Blue as the field colour.

## Palette

| Role | Value | Notes |
|---|---|---|
| Primary | `#0A2463` Deep Muse Blue | backgrounds, headline fields, carousel slides |
| Neutral ink | `#111317` | body text on light fields |
| Neutral paper | `#F7F7F5` | light fields |
| Receipt tint | `#E8EDF7` | code/terminal panels |

Any `visual_brief` that names a hex colour must use a value from this table, otherwise brand
lint raises `OFF_BRAND`. Naming no colour is allowed.
