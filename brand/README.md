# brand/

The brand foundation the engine enforces.

| File | Purpose |
|---|---|
| `foundation.md` | identity, canonical tagline, three stories, Proof-of-Work stance |
| `visual-identity.md` | Deep Muse Blue `#0A2463`, palette, visual rules |
| `banned-and-required.md` | banned filler/hype/status words, required receipts |
| `voice-fingerprint.md` | how Samuel writes + machine-readable lint config (**founder-signed**) |
| `voice-library/` | real Samuel samples only (few-shot for the Producer) |

`brand/` is append-only in practice. Voice changes are founder-signed and arrive as a PR
from the Edit Loop. Nothing here is generated by an agent.
